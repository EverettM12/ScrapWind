# ScrapWind
A Godot 4.7 first-person open-world adventure focused on exploration, traversal, quests, NPCs, boats, combat, and a dynamic world.

`interaction system`

`environmental gameplay`

`day/night cycle`

`world/enviroment system`

`ui system`

`settings system`

`world navigation`
